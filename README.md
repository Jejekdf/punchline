# punchline

A fast, client-side meme generator built with React and HTML5 Canvas.

Live: https://punchline.rnm.biz.id

## Features

- Canvas editor with draggable text, rotation, custom fonts, stroke, and layer controls
- 100+ meme templates via Imgflip API or upload custom images
- Client-side export to PNG
- Private by default: images and text are processed locally in your browser

## Getting Started

```bash
git clone git@github.com:Jejekdf/punchline.git
cd punchline
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS
- HTML5 Canvas API
- Lucide React
